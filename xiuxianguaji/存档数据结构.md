# 修仙40K 存档数据结构文档

## 存储方式

### 本地存档
- **存储位置**: `localStorage`
- **Key**: `xiuxianGame`
- **格式**: JSON 字符串
- **读取方式**: `JSON.parse(localStorage.getItem('xiuxianGame'))`

### 导出存档
- **格式**: Base64 编码的 JSON
- **编码方式**: `btoa(unescape(encodeURIComponent(jsonStr)))`
- **解码方式**: `JSON.parse(decodeURIComponent(escape(atob(base64String))))`

## 完整数据结构

```typescript
interface SaveData {
  version: {
    major: number;      // 主版本号 (当前: 1)
    minor: number;      // 次版本号 (当前: 0)
    patch: number;      // 补丁版本号 (当前: 17)
  };
  
  player: Player;
  inventory: Inventory;
  exploring: ExploreState;
  exploreQueue: ExploreQueueItem[];
  autoExplore: boolean;
  difficulty: 'easy' | 'normal' | 'hard';
  dungeonCooldowns: Record<string, number>;     // 副本ID -> 冷却结束时间戳
  activeBuffs: Record<string, BuffState>;       // buff类型 -> buff状态
  breakthroughBuffs: Record<string, BuffState>; // 大境界ID -> 突破丹buff状态
  usedPermanentPills: Record<string, number>;   // 丹药ID -> 使用次数
  craftedLimitedPills: Record<string, boolean>; // 丹药ID -> 是否已炼制
  gameTimeElapsed: number;                      // 游戏内累计时辰数
  lastSaveTime: number;                         // 上次保存时间戳 (ms)
}
```

## 详细字段说明

### Player (玩家数据)

```typescript
interface Player {
  name: string;           // 道号, 默认: "无名散修"
  uid: string;            // 唯一ID, 格式: "TIMESTAMP-RANDOM-SCREEN-HASH"
  realm: number;          // 境界等级 (0-26), 对应 REALMS 数组索引
  exp: number;            // 当前修为值
  baseSpeed: number;      // 基础修炼速度, 默认: 1
  speedBoost: number;     // 速度加成 (旧版兼容字段)
  speedBoostEndTime: number; // 速度加成结束时间 (旧版兼容字段)
  spiritStones: number;   // 灵石数量
  equipment: {
    weapon: string | null;    // 武器ID
    armor: string | null;     // 护甲ID
    accessory: string | null; // 饰品ID
    treasure: string | null;  // 法宝ID
  };
}
```

### Inventory (背包)

```typescript
interface Inventory {
  materials: Record<string, number>;  // 材料ID -> 数量
  pills: Record<string, number>;      // 丹药ID -> 数量
  equipment: Record<string, number>;  // 装备ID -> 数量
  treasures: Record<string, number>;  // 法宝ID -> 数量
}
```

### ExploreState (探索状态)

```typescript
interface ExploreState {
  active: boolean;    // 是否正在探索
  areaId: string | null; // 探索区域ID
  endTime: number;    // 探索结束时间戳 (ms)
  startTime: number;  // 探索开始时间戳 (ms)
}
```

### ExploreQueueItem (探索队列项)

```typescript
interface ExploreQueueItem {
  areaId: string;     // 区域ID
  endTime: number;    // 结束时间戳
  startTime: number;  // 开始时间戳
}
```

### BuffState (Buff状态)

```typescript
interface BuffState {
  value: number;      // buff数值 (如速度加成百分比)
  endTime: number;    // 结束时间戳 (ms)
}
```

## 仙历时间系统

- 1 真实秒 = 1 时辰
- 12 时辰 = 1 天
- 30 天 = 1 月
- 12 月 = 1 年
- 起始时间: 仙历 40000 年 1 月 1 日 子时
- `gameTimeElapsed` 存储的是累计时辰数

## 兼容性处理建议

1. **版本检查**: 检查 `version.major` 是否一致
2. **字段缺失**: 对可能缺失的新字段使用默认值
   ```javascript
   spiritStones = data.player.spiritStones || 0;
   craftedLimitedPills = data.craftedLimitedPills || {};
   ```
3. **旧版兼容**: `speedBoost` 和 `speedBoostEndTime` 是旧版字段，新版使用 `activeBuffs`
