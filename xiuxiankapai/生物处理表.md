# 生物处理系统表

## 速度系统

### 时间单位

| 单位 | 换算 |
|------|------|
| 刻 | 基础时间单位 |
| 时辰 | 8刻 |

### 速度机制

- **速度值**：生物每刻移动的距离
- **初始距离**：生物生成时与玩家的距离
- **生成规则**：初始距离 = 速度 × 随机时间（2刻 ~ 8时辰）
- **攻击触发**：当距离降为0时，生物对玩家造成伤害

### 初始距离计算

```
最小初始距离 = 速度 × 2刻
最大初始距离 = 速度 × 64刻（8时辰）
```

### 境界速度参考表

| 境界 | 速度范围 | 最小初始距离 | 最大初始距离 | 玩家反应时间 |
|------|----------|--------------|--------------|--------------|
| 凡人境 | 1-5 | 2-10 | 64-320 | 2刻~64刻 |
| 练气境 | 6-12 | 12-24 | 384-768 | 2刻~64刻 |
| 筑基境 | 13-25 | 26-50 | 832-1600 | 2刻~64刻 |
| 金丹境 | 26-45 | 52-90 | 1664-2880 | 2刻~64刻 |
| 元婴境 | 46-70 | 92-140 | 2944-4480 | 2刻~64刻 |
| 化神境 | 71-100 | 142-200 | 4544-6400 | 2刻~64刻 |

> **设计说明**：虽然高境界生物速度更快，但初始距离也更远，玩家的反应时间（2刻~64刻）是相同的。高境界生物的威胁在于更高的伤害和更难击杀。

---

## 处理流程概览

```
【活的生物】
    ↓ 击杀（武器，锋利度≥坚固度）
【死的生物】
    ↓ 剥皮（剥皮工具，锋利度≥坚固度）
【剥皮的生物】+ 未处理皮 + (血)
    ↓ 分解（剥皮工具）
【肉】+【骨】+【特殊产物】+ (妖丹)
```

## 工具类型说明

| 阶段 | 工具类型 | 说明 |
|------|----------|------|
| 击杀 | 武器 | 剑、刀、斧、枪、矛、弓等 |
| 剥皮 | 剥皮工具 | 石刮刀、铜刮刀、铁刮刀等 |
| 分解 | 剥皮工具 | 同上 |
| 收集血液 | 容器 | 木桶、灵木桶等（可选） |
