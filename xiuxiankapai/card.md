## 二、坚固度与锋利度系统

### 2.1 核心规则
- **锋利度 ≥ 坚固度** 时，武器/工具才能对目标进行操作
- 武器用于攻击/击杀（将活物变为死物）
- 工具用于加工/采集（处理材料、剥皮、分解）

## 五、物品加工流程

### 5.1 基础材料加工

#### 植物/药草加工
```
原材料 + 研磨工具 → 粉末
例：草叶 + 石研钵 → 草粉
例：聚灵草 + 灵铁研钵 → 灵药粉
例：雪莲花 + 寒铁研钵 → 筑基灵药粉
```

#### 矿物加工
```
矿石 + 加工工具 + 熔炉 → 矿锭
例：粗铁矿 + 铁锤 + 土制熔炉 → 铁锭
例：灵铁矿 + 灵铁锤 + 灵铁熔炉 → 灵铁锭
例：玄铁矿 + 玄铁锤 + 玄铁炼器炉 → 玄铁锭
```

#### 晶石加工
```
晶石 + 加工工具 → 晶片/晶粉
例：玄水晶 + 黑铁锤 → 玄水晶片
例：火灵晶 + 赤铜锤 → 火晶粉
```

### 5.2 动物/妖兽处理流程

#### 第一步：击杀
```
活的动物/妖兽 + 武器（锋利度≥表皮坚固度） → 死的动物/妖兽
例：活的野猪 + 铁剑（锋利度10≥坚固度5） → 死的野猪
例：活的火蜥蜴 + 黑铁剑（锋利度17≥坚固度16） → 死的火蜥蜴
```

#### 第二步：剥皮
```
死的动物/妖兽 + 剥皮工具 → 剥皮的动物/妖兽 + 未处理的皮
死的动物/妖兽 + 剥皮工具 + 容器 → 剥皮的动物/妖兽 + 未处理的皮 + 动物/妖兽血

例：死的野猪 + 铁刮刀 → 剥皮的野猪 + 未处理的野猪皮
例：死的野猪 + 铁刮刀 + 木桶 → 剥皮的野猪 + 未处理的野猪皮 + 野猪血
例：死的火蜥蜴 + 黑铁刮刀 + 灵木桶 → 剥皮的火蜥蜴 + 未处理的火蜥皮 + 火蜥血
```

#### 第三步：分解
```
剥皮的动物/妖兽 + 剥皮工具 → 肉 + 骨 + [妖丹（金丹境及以上）]

例：剥皮的野猪 + 铁刮刀 → 野猪肉 + 野猪骨 + 獠牙
例：剥皮的火蜥蜴 + 黑铁刮刀 → 火蜥肉 + 火蜥骨 + 火蜥胆
例：剥皮的冥海蛟 + 深海铁刮刀 → 蛟肉 + 蛟骨 + 蛟筋 + 蛟丹
```

#### 第四步：皮革加工
```
未处理的皮 + 加工工具 + 鞣制材料 → 皮革

凡人境：未处理的兽皮 + 铁锤 + 草粉×3 → 皮革
练气境：未处理的妖皮 + 精铁锤 + 灵药粉×3 → 妖皮革
筑基境：未处理的灵兽皮 + 玄铁锤 + 筑基灵药粉×3 → 灵兽皮革
金丹境：未处理的金丹妖皮 + 秘银锤 + 金丹灵药粉×3 → 金丹妖皮革
```
